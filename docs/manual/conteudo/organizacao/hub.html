Para que serve

Configurações é o painel que reúne todas as telas de ajuste do sistema. Fica sempre no rodapé do menu lateral, com ícone de engrenagem, logo acima de “versão X.Y.Z”. Cada tela é um cartão com nome, uma frase explicando o que ela faz e uma seta.

  1. Sua empresa. A primeira seção: regras do negócio (agenda, propostas, financeiro, equipe, atendimento, tags, marca…).
  2. Sua conta. Perfil, Segurança e Notificações — só o que é seu.
  3. Dados e acesso. LGPD, chaves de API, linha telefônica e dados externos.
  4. Um cartão. Clique para abrir a tela (aqui, Equipe).
  5. Outro cartão (aqui, Organização, que só o Administrador vê).
A ordem das seções.

Apesar do nome, “Sua empresa” vem antes de “Sua conta” e de “Dados e acesso”.

  • Administrador vê tudo.
Cartão que pode levar a “não encontrado”.

“Modelos de proposta” aparece para o Gerente mesmo quando o módulo Propostas está desligado na instalação; nesse caso o clique cai numa página “não encontrada”. É um detalhe conhecido do hub (deduzido do código).

Telas que existem mas não têm cartão

  • Atualização do sistema — só o dono do servidor; chega-se pelo rodapé do menu lateral (“Nova versão · X.Y.Z”).
  • Antigos endereços de WhatsApp (/app/settings/canal-oficial, /templates e /tenant/whatsapp) apenas redirecionam para Conexões.
  • Etapas do funil pertence ao grupo CRM, não a este.

O Administrador pode esconder cartões e itens de menu da empresa (e de cada pessoa) pela escolha de “Interface”. Os cartões essenciais nunca somem: Perfil e Segurança para todos; Equipe e Organização para o Administrador.
