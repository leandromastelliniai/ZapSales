Para que serve

Mostra a versão instalada no servidor e, quando há uma nova, o que muda nela — e deixa o dono mandar o servidor atualizar. É uma tela do servidor, não da empresa: “Administrador” da empresa não a vê (recebe “página não encontrada”), e ela não tem cartão no hub Configurações. A porta é o rodapé do menu lateral: mostra “versão X.Y.Z” e, só para o dono, quando há versão nova, vira o link “Nova versão · X.Y.Z” com um ponto pulsando (uma seta quando o menu está recolhido).

A captura mostra o estado em que o sistema não consegue falar com o servidor onde está instalado: “Quem tem acesso ao servidor pode entrar na pasta onde o sistema foi instalado e rodar este comando — se for a primeira vez, rode duas vezes: a primeira baixa o programa novo e a segunda liga o botão desta tela.” O comando é bash kit/update.sh, com o botão Copiar. Abaixo do comando, a linha “Versão instalada:” mostra o número, ou “ainda não informada pelo servidor” quando o servidor nunca respondeu desde a instalação.

Os estados da tela

A descrição padrão é “A versão instalada no servidor e, quando houver uma nova, o que muda nela.” Cada estado tem título próprio:

TítuloO que significa e o que fazer
Carregando…Lendo a versão.
Você está na versão X“É a mais recente. Não há nada a fazer.”
Versão X disponívelMostra a caixa “⚠️ Requer atenção” (“Da versão X:” com avisos de ação manual), o aviso de histórico incompleto, a seção “O que muda” (notas da versão-alvo abertas; as intermediárias recolhidas) e o botão Atualizar agora (“Iniciando…”) com a nota “O sistema sai do ar por cerca de 2 minutos e volta sozinho. Faço uma cópia de segurança dos seus dados antes.” Em instalação de desenvolvimento aparece um aviso amarelo de que a atualização leva à versão publicada.
Pedido enviado — esperando o servidor pegarO servidor confere se há algo a fazer “de poucos em poucos minutos”, então a atualização pode levar até cerca de cinco minutos para começar; ficar parada nesse tempo é normal. “Pode fechar esta página: o pedido já está registrado e não se perde.”
Atualizando para a versão XQuatro passos com ✓/○: “Guardando uma cópia de segurança dos seus dados”, “Baixando a versão nova”, “Atualizando o banco de dados”, “Reiniciando o sistema”. Depois, “Reiniciando…”: “O sistema está voltando. Esta página se atualiza sozinha em alguns instantes.”
A atualização para a versão X terminouQuando o servidor ainda não confirmou em que versão voltou ao ar, mostra a última confirmada.
…não deu certo / “Não sei dizer como terminou”Voltou atrás ou não conseguiu voltar. Mostra comandos para rodar no servidor (bash kit/update.sh --to vX.Y.Z --force) e “Detalhes técnicos (útil se for pedir ajuda)”.
Atualização automática indisponívelVeja acima: rode o comando no servidor.
“Não consegui checar se há versão nova”, “Ainda não há nenhuma versão publicada”, “Você está à frente da versão publicada”Casos de borda; a tela explica cada um.
Atualizar tira o sistema do ar para todos.

O pedido é anotado e o agente do servidor (que confere a cada ~5 minutos) faz a cópia de segurança, baixa a versão, atualiza o banco e reinicia: o sistema fica fora do ar por cerca de 2 minutos para TODAS as empresas e usuários da instalação. Registra o pedido (system.update_requested) e o fim (system.update_finished) na Auditoria. Esta tela não foi acionada nas capturas; atualização é um ato de operação do servidor, não do uso diário. Para a regra de versões e o que cada versão traz, veja o histórico de mudanças (changelog) do produto.
