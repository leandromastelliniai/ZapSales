Para que serve

Uma chave de acesso (token) é como uma senha para outro sistema — o seu site, um ERP, um agente de IA externo — falar com o ZapSales sem precisar de login de pessoa. Aqui o Administrador cria e revoga essas chaves. Quem tiver a chave age na empresa, dentro dos escopos escolhidos, trate-a como uma senha.

  1. Criar token.
  2. Nome. O nome que você deu.
  3. Prefixo. zps_xxxxxxxx…, só os primeiros caracteres, para você reconhecer a chave. O prefixo é sempre zps_.
  4. Escopos. Etiquetas com o que a chave pode fazer.
  5. Status. Ativo ou Revogado.
  6. Expira. A data, ou “—” (não expira).
  7. Revogar. Só nas chaves ativas, sem janela de confirmação (“Token revogado.”).

Vazio: “Nenhum token criado ainda.”. A tabela não mostra o “último uso”, embora o sistema o guarde.

Criar uma chave

  1. Nome. De 2 a 100 caracteres (“Worker de import”).
  2. Escopos. Marque ao menos um (“Selecione ao menos um escopo.”).
  3. role:manager. Faz a chave valer como Gerente. Sem ele a chave age como Atendente.
  4. Expira em (dias) — opcional. De 1 a 365; em branco = nunca expira.
  5. Criar.
EscopoO que permite
mcp:readAgentes de IA podem ler o CRM (protocolo MCP).
mcp:writeAgentes de IA podem agir no CRM (MCP).
role:managerTratar a chave como Gerente (necessário para criar e atribuir).
contacts:read / contacts:writeLer contatos / criar e editar contatos.
leads:read / leads:writeLer leads / criar e editar leads.
messages:read / messages:writeLer mensagens / enviar mensagens.
messages:on_behalfA integração pode enviar em nome de um atendente.
audit:readLer o log de auditoria.

O texto da chave aparece uma única vez

  1. Copie e guarde agora. “não conseguiremos exibir novamente.”
  2. Copiar para clipboard. “Token copiado.”
  3. Aviso. “Salve este token agora — ele não será mostrado novamente.”
  • O formato é zps_<8 caracteres>_<segredo>. O servidor guarda só uma impressão digital (hash SHA-256) e o prefixo; o texto completo nunca volta. Perdeu? Revogue e crie outra.
  • A chave vai no cabeçalho Authorization: Bearer zps_…, nunca na URL.
  • Revogar faz a chave deixar de valer na hora e é irreversível; ela continua na lista como “Revogado”.
  • No máximo 50 chaves ativas por empresa (as revogadas e vencidas não contam): “Teto de tokens ativos por organização atingido: N de 50.”
  • Criar e revogar ficam na Auditoria (token.created, token.revoked). Não envia e-mail.
Nem toda rota aceita chave.

A habilitação é por rota (cerca de 20 rotas da API e o endereço do MCP). O sistema aceita qualquer texto como escopo, mas a tela só oferece estes 11. A expiração é só por data.
