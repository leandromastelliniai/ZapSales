Para que serve

É a sua biblioteca de textos prontos: a saudação, o horário de funcionamento, o endereço, a chave Pix. Em vez de digitar de novo a cada conversa, você guarda uma vez e puxa no Inbox em dois toques. Cada resposta pode ser pessoal (só você vê) ou compartilhada (toda a equipe usa).

Não confunda com os “templates” da Meta.

O nome técnico aqui é “template”, mas estas são mensagens livres da sua equipe. Os modelos aprovados pela Meta (necessários para falar com um cliente depois de 24 horas na API Oficial) ficam em Conexões, não aqui. Nada nesta tela envia mensagem nem chama serviço externo.

  1. Como funciona. Abre o painel de ajuda.
  2. Novo template. Cria uma resposta nova.
  3. Um cartão. Mostra o título, o selo e a mensagem (até duas linhas). A lista fica em ordem de última alteração, a mais recente primeiro.
  4. Selo “Compartilhado”. Toda a equipe vê e usa essa resposta.
  5. Selo “Pessoal”. Só você vê.
  6. Lápis (editar). Só aparece se você pode alterar aquela resposta.
  7. Lixeira (excluir). Idem. Pede confirmação e não tem volta.

Quando a lista está vazia, a tela diz “Nenhum template ainda.”.

Criar ou editar uma resposta

  1. Título. Obrigatório, de 1 a 80 caracteres (exemplo: “Saudação inicial”). É o que você procura depois.
  2. Mensagem. O texto que será colocado no campo de resposta, de 1 a 4.096 caracteres. Use {{primeiro_nome}} e {{nome}} para personalizar: o Inbox troca pelo nome do contato.
  3. Atalho (opcional). Uma palavra curta, até 40 caracteres (por exemplo “oi” ou “pix”). Dá para chamar a resposta digitando / e o atalho.
  4. Compartilhar com a equipe. Só aparece para Gerente ou acima. Depois de criada, a resposta não pode passar de pessoal para compartilhada nem o contrário: ao editar, o interruptor continua visível, mas travado.
  5. Criar template (na edição, Salvar). Grava e mostra “Template criado.”.
  • Os marcadores {{nome}} e {{primeiro_nome}} são os únicos trocados. Se o contato não tem nome, o texto sai como está escrito.
  • O atalho não precisa ser único.
  • Ao editar, a janela se chama “Editar template” e, ao salvar, mostra “Template atualizado.”.
  • Excluir mostra “Excluir este template?” — “Essa ação não pode ser desfeita.” — e, depois de confirmar, “Template excluído.”.
  • Um link do tipo /app/templates?modelo=… (o que uma integração devolve para indicar “use este modelo”) abre direto a janela de edição daquela resposta, mas só para quem pode editá-la. Quem só pode usar (por exemplo, um Atendente diante de uma resposta compartilhada) fica na lista, onde a resposta está visível.

Usar no Inbox

  1. Abra uma conversa no Inbox.
  2. No campo de resposta, digite /. Abre o menu “Templates de script”.
  3. Continue digitando para filtrar: aparecem as respostas cujo título ou atalho contêm o que você digitou (não importa se maiúscula ou minúscula). Escolha uma. Se nenhuma servir, o menu diz “Nenhum template. Crie em Configurações.” — a tela certa para criar é esta, Respostas rápidas.
  4. O texto entra no campo, já com o nome do cliente no lugar dos marcadores. Ele não é enviado sozinho: revise e envie quando quiser.
O menu só abre no começo.

O “/” precisa ser o primeiro caractere do campo e não pode ter espaço depois dele.

Quem pode o quê

PapelO que pode
Somente leituraAbre a página, mas não consulta a lista: vê “Nenhum template ainda.”.
AtendenteCria respostas pessoais e edita ou exclui as suas. Usa as compartilhadas.
Gerente e AdministradorTudo isso, mais criar respostas compartilhadas e editar ou excluir as compartilhadas.

As respostas pessoais só são vistas por quem as criou; as compartilhadas, por toda a organização. As ações ficam registradas na auditoria (template.created, template.updated, template.deleted).

Comece pelas perguntas que você mais responde.

Horário, endereço, formas de pagamento, prazo de entrega. Deixe-as compartilhadas e peça à equipe para usar sempre a mesma.
