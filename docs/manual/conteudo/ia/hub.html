Para que serve

O menu lateral mostra só três itens da área de IA — Agentes, Follow-ups e Casos —, porque são os de uso diário. O item Ver tudo em IA abre esta página, com todas as telas da área, agrupadas pelo que você quer fazer.

  1. Montar o agente. As telas onde você define quem atende: Agentes, Follow-ups, Roteadores, Credenciais e Provedores (mais Fluxos de atendimento, quando esse módulo opcional está ligado).
  2. Cada linha tem o nome da tela, uma frase explicando o que ela faz e uma seta. Clique para abrir.
  3. Ensinar o agente. Conhecimento, Memória e Skills.
  4. Acompanhar o agente. Casos, Alertas, Aviso no WhatsApp, Sugestões da IA, Execuções e Uso e orçamento.

Quem vê o quê

A página abre para qualquer pessoa logada, mas esconde o que o seu papel não alcança. Um Gerente vê quase tudo; um Atendente vê só Casos, Alertas e Sugestões da IA; o Aviso no WhatsApp só aparece para Administrador. Se você não vê um cartão, é o papel — veja Papéis.

Padrão da área de IA: Gerente vê, Administrador altera.

Quase todas as telas de montagem abrem para o Gerente, mas os botões que gravam (criar agente, publicar, cadastrar chave, trocar provedor) só funcionam para o Administrador. O Gerente enxerga os campos travados.

O hub depende da sua configuração.

A empresa pode simplificar o menu (em Configurações › Organização), o que esconde alguns cartões. Telas de módulos opcionais, como Fluxos de atendimento, só aparecem quando o módulo está ligado na instalação.
