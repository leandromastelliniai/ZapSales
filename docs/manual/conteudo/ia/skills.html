Para que serve

Uma skill é uma “receita” especializada que o agente só consulta quando o assunto pede. Em vez de encher as instruções de todo agente com tudo, a skill entra em ação quando o cliente escreve uma das palavras-chave dela. Exemplos: um passo a passo para contornar a objeção “está caro” ou para marcar e remarcar horário.

  1. Enviar skill (.zip). Instala uma skill sua, empacotada num arquivo .zip.
  2. Selo “do catálogo”. A skill veio de uma cópia do catálogo da plataforma.
  3. Editar. Ajusta o texto de uma skill instalada. Veja Editar uma skill.
  4. Desinstalar. A skill deixa de valer para os agentes. Não pede confirmação.
  5. Aviso informativo. Lembra que cada salvamento cria uma versão nova e a anterior fica no histórico, e que reenviar um .zip com o mesmo nome substitui a skill.
  6. Catálogo. As skills prontas, mantidas pela plataforma, que você ainda não instalou. Quando já instalou tudo, a tela diz que não há skill nova.
  7. Instalar. Cria uma cópia da sua organização da skill, que passa a valer na hora para os agentes.

Uma skill que você mesmo enviou aparece com o selo manual no lugar de do catálogo. A skill foi enviada por você (ou criada à mão).

Desde o fim de outubro, “Skills instaladas” e “Catálogo” são dois painéis com título e uma linha por skill (o botão Enviar skill (.zip) fica no canto do primeiro painel), e os selos “do catálogo” e “manual” são cinza, sem cor de destaque. Os botões e o que fazem são os mesmos da legenda.

Cada skill instalada mostra o nome, o selo de origem, a data de “atualizada em” e a descrição. Sem nenhuma instalada, a tela diz “Nenhuma skill instalada ainda…”. A lista e os botões (Enviar, Editar, Desinstalar, Instalar, Adotar versão nova) só aparecem para quem pode gerenciar skills; quem só consulta vê a lista sem os botões.

O catálogo da plataforma

Hoje o catálogo traz duas skills:

  • objecao-preco: um playbook para contornar objeção de preço no WhatsApp. Diagnostica o motivo real por trás do “caro” antes de reagir, sem ceder desconto não autorizado.
  • agendamento: um playbook para marcar e remarcar horário (consulta, visita, sessão). Consulta a agenda real pelas ferramentas quando elas existem, nunca inventa disponibilidade e confirma por escrito antes de fechar.

Quando a plataforma publica uma versão nova de uma skill que você já instalou, aparece uma faixa avisando, com o que mudaria (descrição, palavras-chave, procedimento) e o botão Adotar versão nova. Se você tinha editado a sua cópia, as edições ficam só no Histórico de versões: ao adotar, a versão nova do catálogo passa a ser a ativa. Confira antes.

Editar uma skill

Clique em Editar. A janela pede:

  • Descrição (obrigatória, até 500 caracteres, uma linha): aparece no índice de skills que o agente enxerga.
  • Palavras-chave de ativação (separadas por vírgula; pelo menos uma): a skill é carregada quando o cliente escreve uma dessas palavras. Exemplo: consulta, horário, preço.
  • Corpo: o procedimento que o agente segue, em texto. O limite é de 200 linhas; o contador fica vermelho acima disso.
  • Histórico de versões: cada salvamento cria uma versão nova. A atual aparece como “em uso”; nas outras há o botão Restaurar.

Salvar cria uma versão nova (a antiga continua no histórico) e vale de imediato para os agentes. Uma skill que veio de um pacote com arquivos (pastas de referência) não pode ser editada aqui: edite o pacote e envie o .zip de novo.

Enviar uma skill sua (.zip)

  1. Monte uma pasta com um arquivo SKILL.md na raiz. Ele começa com um cabeçalho entre linhas --- contendo name, description e matcher (com a lista any_keywords), e abaixo vem o procedimento, em até 200 linhas.
  2. Se quiser, inclua as pastas references/ e assets/ (imagens, PDF, áudio ou vídeo permitidos).
  3. Compacte em .zip e clique em Enviar skill (.zip). Limites: até 64 arquivos, 5 MB descompactado, 1 MB por arquivo, 6 MB de envio.

O nome da skill só aceita letras sem acento, números, ponto, hífen, sublinhado e espaço. Enviar um .zip com o mesmo nome de uma skill instalada a substitui (nova versão), inclusive a que veio do catálogo.

Cuidados

Skill gasta IA a cada uso.

Quando uma skill é ativada, o corpo dela vai junto na resposta do agente, o que aumenta o gasto daquele atendimento. Skills enxutas custam menos.

“Do catálogo” continua valendo depois de editar.

O selo só diz de onde a skill veio. Uma skill do catálogo que você editou continua com o selo.
