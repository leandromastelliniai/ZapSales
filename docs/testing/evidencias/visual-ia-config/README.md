# Evidência visual: listas de IA em linhas dentro de um painel

- `antes-producao-*` — as telas reais na produção (organização temporária, dados semeados), antes da mudança.
- `depois-vitrine-*` — os mesmos componentes reais com dados de exemplo, em 1440 px e 390 px, depois da mudança.
  A prova pela tela em produção depois do deploy está descrita no PR.
